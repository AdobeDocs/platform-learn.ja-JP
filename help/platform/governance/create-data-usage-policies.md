# データ使用ポリシーの作成

Adobe Experience Platform ユーザーインターフェイスでデータ使用ポリシーを作成および管理する方法について説明します。 データ使用ポリシーを使用すると、データのラベル付けに基づく特定の目的に対するデータ使用を制限できます。API ベースのアプローチについては、[API を使用したデータ使用ポリシーの作成 &#x200B;](https://experienceleague.adobe.com/docs/experience-platform/data-governance/policies/create.html?lang=ja) を参照してください。

# はじめに – GenStudio

このモジュールでは、お使いの環境とコンピューターがGenStudio Tech Labsを使い始める準備ができるように、すべての設定を行います。

## 学習内容

- Chrome拡張機能の設定方法を説明します
- Adobe I/O プロジェクトとPostmanまたはPostbusterの設定
- GenStudio Tech Labsの受講に必要なアプリケーションをインストールする

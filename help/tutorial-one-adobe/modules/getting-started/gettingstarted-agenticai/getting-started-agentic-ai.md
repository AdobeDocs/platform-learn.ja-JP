# はじめに – Agentic AI

このモジュールでは、環境とコンピューターがエージェンティック AI ラボの受講を開始できるように、すべてを設定します。

## 学習内容

- Chrome拡張機能の設定方法を説明します
- web サイトの活用方法を学ぶ
- Agentic AI Labsを利用するために必要なアプリケーションをインストールする

## 演習

学習パスに応じて、以下の演習のいくつかは必要ですが、他の演習は必要ない場合があります。

[Experience League ドキュメント用のChrome拡張機能のインストール](./ex1.md)

この演習では、Chrome拡張機能をインストールして設定し、チュートリアルコンテンツのパーソナライズに使用できるようにします。

[インストールするアプリケーション](./ex2.md)

この演習では、チュートリアルを開始する前に、コンピューターに必要なすべてのアプリケーションをインストールする方法について説明します。

[AEMのweb サイトとAEPサンドボックスの使用](./ex3.md)

この演習では、web サイトを設定して、デモやイネーブルメントに使用できるようにします。

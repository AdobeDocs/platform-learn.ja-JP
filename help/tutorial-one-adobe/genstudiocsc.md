# 概要 – GenStudio Tech Labs

![技術関係者](./assets/images/techinsiders.png){width="50px" align="left"}

## 概要

Adobe GenStudio for Content Supply chain Technical Enablementのライブワークショップへのご参加は、テックラボの出発点となります。

このテクニカルイネーブルメントワークショップの一環としてTech Labsでは、以下のアプリケーションについて実践的に学ぶことができます。

- Adobe Firefly Services
- Adobe Frame I/OおよびAdobe Premiere Pro
- Adobe Workfront Workflow &amp; Adobe Workfront Planning
- Adobe Experience Manager Cloud Service Assets
- Adobe Journey Optimizer

今回参加するTech Labsは、One Adobeのチュートリアルの一部であり、Adobe Creative CloudとAdobe Experience Cloudの広範なソリューションについて、さらに詳しく学ぶことができます。 利用可能なものを確認したい場合は、こちらをご覧ください。[Adobe チュートリアルの概要](./overview.md)

## GenStudio Tech Labs

以下は、このテクニカルイネーブルメントワークショップの一部として参加するTech Labsです。

### はじめに

[はじめに](./modules/getting-started/gettingstarted/getting-started.md){target="_blank"}

この基本モジュールでは、デモ環境にアクセスして使用できるように、すべてを準備します。

### ワークフロー/プランニング

[1.1 Adobe Workfront計画](./modules/workflow-planning/module1.1/wfplanning.md){target="_blank"}

このモジュールでは、Adobe Workfront Planningを設定および使用して、新しいワークスペースの作成、レコードタイプの定義、レコードの管理、新しいリクエストフォームの作成、AI アシスタントの活用を行います。

[1.2 Adobe Workfront Workflow](./modules/workflow-planning/module1.2/workfront.md){target="_blank"}を使用したワークフロー管理

このモジュールでは、Adobe Workfrontを使用して承認フローを設定および管理し、Adobe Experience Manager Assets、ユニバーサルエディター、Photoshopなどの統合機能を使用します。

### コンテンツ制作

[1.1 Adobe Firefly Servicesの概要](./modules/creation-production/module1.1/firefly-services.md){target="_blank"}

このモジュールでは、Adobe Firefly Services API、Photoshop API、Microsoft Azure Storage Servicesを使用して画像を生成し、プログラムで保存します。

[1.2 Workfront Fusionを使用したCreative Workflow Automation](./modules/creation-production/module1.2/automation.md){target="_blank"}

Adobe Workfront Fusionを使用して、コンテンツ制作ワークフローを自動化し、規模を拡大します。

[1.3 GenStudio for Performance Marketing](./modules/creation-production/module1.3/genstudio.md){target="_blank"}

このモジュールでは、Adobe GenStudio for Performance Marketingを使用します。これは、マーケティングチームとクリエイティブチームが連携し、デジタルマーケティングキャンペーン向けのエンタープライズガバナンス機能を備えたオムニチャネルコンテンツを制作、活用、最適化するための、生成AIを利用したエンドツーエンドのワークフローアプリケーションです。

[1.4 Adobe ExpressとAdobe Experience Cloud](./modules/creation-production/module1.4/express.md){target="_blank"}

このモジュールでは、Adobe Expressを使用して画像や動画を制作し、これらのアセットをより広範なAdobe Experience Cloudエコシステムと共有します。

[1.5 Frame.ioでワークフローを効率化](./modules/creation-production/module1.5/frameio.md){target="_blank"}

このモジュールでは、Adobe Frame.ioとAdobe Premiere Proを組み合わせて、画像やビデオの共同作業とレビューを行います。

[1.6 GenStudio for Performance Marketing – 拡張性](./modules/creation-production/module1.6/genstudioext.md){target="_blank"}

このモジュールでは、Adobe IOとApp Builderを使用して、GenStudio for Performance Marketingの機能を拡張するカスタムアプリケーションを構築します。

[1.7 Firefly カスタムワークフロー](./modules/creation-production/module1.7/workflowbuilder.md){target="_blank"}

このモジュールでは、Fireflyのカスタムワークフローを使用して、繰り返し可能なクリエイティブデザインと自動化のユースケースを解決します。

[1.8 Workfront、Frame.io、Enterprise Storage Managementによる統一されたレビューと承認](./modules/creation-production/module1.8/esm.md){target="_blank"}

Workfrontのプロジェクト管理機能と作業管理機能を、Frame.ioのリアルタイムのレビューおよび共同作業エクスペリエンスに直接接続して、活用します。

### アセット管理とサイト

[1.1 Adobe Experience Manager Cloud ServiceとEdge Delivery Services](./modules/asset-mgmt/module2.1/aemcs.md){target="_blank"}

このモジュールでは、Adobe Experience Manager Cloud Service プログラム、サイト、Assets リポジトリを設定します。

[1.2 Adobe Experience Manager Assets](./modules/asset-mgmt/module2.2/aemassets.md){target="_blank"}

AEM Assetsの概要。

[1.3 Adobe Experience Manager FormsとEdge Delivery Services](./modules/asset-mgmt/module1.3/aemforms.md){target="_blank"}

Edge Delivery Servicesを活用して、Adobe Experience Manager Formsの能力を引き出す方法を解説します。

[1.4 Adobe Experience Manager AssetsとDynamic Media](./modules/asset-mgmt/module1.4/aemassetsdm.md){target="_blank"}

このモジュールでは、AEM Assets Dynamic Mediaを設定し、Adobe Journey OptimizerでDynamic Media テンプレートを使用します。

[1.5 Adobe Commerce as a Cloud Service](./modules/asset-mgmt/module1.5/accs.md){target="_blank"}

このモジュールでは、Adobe Commerce as a Cloud Service インスタンスを作成します。 Commerce インスタンスをAEM Sites CS ストアフロントおよびAEM Assets CS環境に接続します。

[1.4 Brand Concierge](./modules/agents/module1.4/brandconcierge.md)

**目標**

Brand Conciergeは、企業がweb サイト訪問者との関わり方を変革する、AIを活用したデジタルコンパニオンです。 一般的なチャットボットとは異なり、Brand Conciergeは、訪問者一人ひとりの意図に合わせてパーソナライズされた、会話体験を提供します。 訪問者が商品を見つけて比較し、即座に回答を得て、リアルタイムでガイド付きのレコメンデーションを受け取るのに役立ちます。 このプラットフォームは、B2CとB2Bの両方に対応し、ブランドボイス、コンテンツの整合性、コンプライアンスを維持しながら、あらゆるデジタルチャネルをまたいで、ブランドのインテリジェントな拡張機能として機能します。

この演習では、次の操作を行う方法について説明します。

- Adobe Experience Platform サンドボックスでのBrand Concierge インスタンスの設定
- AEM CS/EDS web サイトでのBrand Conciergeの実装

[1.5分析とエージェント](./modules/agents/module1.5/analyticsagents.md)

この演習では、次の操作を行う方法について説明します。

[1.6 AEM &amp; Agents](./modules/agents/module1.6/aemagents.md){target="_blank"}

**目標**

現在、Adobe Experience Managerには複数のエージェントが組み込まれており、それぞれが従来は手作業が必要だった作業を引き受けるように設計されています。 これらは一般的なAI アシスタントではなく、AEMを深く理解し、コンテンツ、コード、アセット、ガバナンス、最適化をまたいで動作する、ドメインをまたいでトレーニングされたエージェントです。

- **Experience Production Agent**：更新、コンテンツの変更、サイト全体の移行を高速化できます。
- **ガバナンスエージェント**&#x200B;は、ブランド、権利、およびコンプライアンスのルールを自動的に適用します。
- **Discovery Agent**&#x200B;は、AI ネイティブな発見のためのコンテンツを準備し、インテリジェントな戦略家として活動します。
- **Content Optimization Agent**&#x200B;は、パフォーマンスに対応したチャネル固有のアセットバリエーションを即座に作成します。
- **開発エージェント**&#x200B;は、AIを活用したトラブルシューティングとパフォーマンス調整によって開発者を高速化します。

この演習では、カスタム MCP サーバー設定を通じて、AI アシスタントとカーソルの両方を使用してこれらのエージェントを使用する方法を学習します。

[1.7 Adobe Commerceのインテリジェントな開発ツール](./modules/agents/module1.7/aiassisteddev.md)

**目標**

Cursorなどのインテリジェントな開発者向けツールを使用して、Adobe Commerce as a Cloud Serviceの拡張機能を開発します。 この拡張機能の目的は、受信オーダーイベントをサードパーティのエンドポイントに転送することです。 Adobe Commerce as a Cloud Serviceでのイベント転送は、Adobe I/O App Builder、Adobe I/O Events、Adobe I/O Runtimeを基盤としています。 これらすべてのサービスの設定は、Cursorによって支援されます。
